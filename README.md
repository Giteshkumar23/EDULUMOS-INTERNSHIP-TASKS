## 📁 Internship Projects

The following projects were completed during my internship:

### 1. Student Data Analysis
📂 `Task01_Student_Data_Analysis`

- Analyzed student-related data.
- Explored and understood dataset characteristics.
- Practiced data cleaning and analysis.

### 2. Titanic Data Analysis
📂 `Task02_Titanic_Data_Analysis`

- Worked with the Titanic passenger dataset.
- Explored passenger information and survival patterns.
- Performed exploratory data analysis.
