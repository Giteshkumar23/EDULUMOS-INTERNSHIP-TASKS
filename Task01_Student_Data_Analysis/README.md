# Task 01: Student Data Analysis

## Project Overview

This project explores student performance in mathematics, reading, and writing. The main goal is to understand the dataset, calculate useful statistics, and visualize patterns in student scores.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Work Completed

- Loaded and explored the student performance dataset
- Checked missing values and duplicate records
- Reviewed statistical summaries
- Visualized the distribution of student scores
- Compared average scores by test preparation and gender
- Analyzed average scores by parental education level
- Created an average score column
- Explored correlations between subject scores
- Saved the analyzed dataset and correlation results

## Project Files

- `StudentsPerformance.csv` — dataset used for analysis
- `student_analysis.ipynb` — notebook containing the analysis and visualizations
- `outputs/student_data_analyzed.csv` — analyzed dataset
- `outputs/score_correlation.csv` — correlation results

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install pandas matplotlib seaborn jupyter`

3. Open `student_analysis.ipynb` in VS Code or Jupyter Notebook.
4. Select a Python kernel.
5. Run the notebook cells in order.

Through this project, I practiced data exploration, data quality checks, descriptive statistics, and data visualization using Python. This project helped me understand how to analyze student performance and identify patterns in the data.
