
# Titanic Data Analysis

## Project Overview
This project focuses on analyzing the Titanic dataset using Python. The main goal is to understand passenger survival patterns through data cleaning, exploratory data analysis, and visualization.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Project Steps
1. Loaded and explored the Titanic dataset.
2. Checked missing values.
3. Cleaned missing data.
4. Analyzed survival by gender and passenger class.
5. Visualized passenger survival and age distribution.
6. Created a correlation heatmap.
7. Saved the cleaned dataset, charts, and analysis summary.

## Key Findings
- Passenger survival differed by gender.
- Survival rates varied across passenger classes.
- Passenger ages and ticket fares varied considerably.
- Visualizations helped identify patterns in the dataset.

## Project Structure
- `data/` — Original dataset
- `outputs/` — Cleaned data, charts, and summary report
- `titanic_analysis.ipynb` — Jupyter Notebook containing the analysis

## How to Run
1. Install the required libraries.
2. Open `titanic_analysis.ipynb` in VS Code.
3. Select your Python environment.
4. Run the notebook cells from top to bottom.
