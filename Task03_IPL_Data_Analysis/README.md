
# IPL Data Analysis

## Project Overview
This project explores Indian Premier League (IPL) cricket data using Python. It analyzes match results, team performance, player statistics, and scoring patterns through data analysis and visualization.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Project Activities
1. Loaded and explored IPL datasets.
2. Examined dataset columns and data quality.
3. Analyzed match results and team wins for 2025.
4. Identified leading run scorers and wicket-takers for 2025.
5. Analyzed team runs and leading run scorers using the 2026 ball-by-ball dataset.
6. Created charts and saved analysis outputs.

## Project Structure
- `data/` — IPL match and ball-by-ball CSV files
- `outputs/` — Charts, summaries, and analysis results
- `ipl_analysis.ipynb` — Jupyter Notebook containing the analysis

## How to Run
1. Install the libraries listed in `requirements.txt`.
2. Open `ipl_analysis.ipynb` in VS Code.
3. Select the appropriate Python environment.
4. Run the notebook cells in order.

## Important Note
The analysis depends on the completeness and accuracy of the supplied datasets. The 2025 and 2026 datasets may have different column formats and coverage.

This project is intended for educational purposes.
